# 敵キャラクター及びボスの攻撃力増加ピッチ緩和 計画書

敵とボスの攻撃力上昇ペースを大幅に緩和し、小学生のお子様でも防具の防御効果をしっかり実感しながら安心して長く遊べるバトルバランスへ再調整します。

---

## ユーザー確認・決定事項

> [!IMPORTANT]
> ユーザーへの事前ヒアリングにより、以下のゲームバランス調整方針が確定しました。

- **確定事項 1（通常敵の攻撃力）**: **5ステージごとに+1** 加算（HPの増加ペース「5ステージごとに+1」と同期）。
  - 新計算式: `1 + Math.floor((stage - 1) / 5)`
  - ステージ1〜5: 攻撃力 1
  - ステージ6〜10: 攻撃力 2
  - ステージ11〜15: 攻撃力 3
  - ステージ16〜20: 攻撃力 4
- **確定事項 2（ボスの攻撃力）**: 通常敵の1.5倍から **倍率なし（通常敵と同じ攻撃力）** に変更。
  - ボスの攻撃力 = その出現ステージの通常敵攻撃力と同じ。
  - ※ボスのHP（通常敵の2倍）および出題問題のステージ+1設定は維持され、タフでやりごたえのあるボス戦の個性は保たれます。

---

## 1. 概要とバランス設計

### 変更前の課題
- 従前の設定（2ステージごとに攻撃力+1、ボスは1.5倍）では、ステージ15時点で通常敵の攻撃力が8、ボスの攻撃力が12まで急激に上昇していました。
- プレイヤー初期HPが5であるため、防具（革:+1、鉄:+3、ダイヤ:+5）を購入していても、中盤以降の数問のミスで即ゲームオーバーになりやすい状況でした。

### 調整後の効果
- 攻撃力の増加が「5ステージごとに+1」と極めてマイルドになり、ステージ1〜5の間は被ダメージが基礎値「1」で安定します。
- 防具を1段階強化するごと（革のふく: 被ダメ-1など）に目に見えて被ダメージをカットできるようになり、ショップでの装備購入の達成感とお得感が大幅に向上します。

```
【攻撃力・被ダメージ推移の比較】

 ステージ     旧仕様 (敵Atk / ボスAtk)    新仕様 (敵Atk / ボスAtk)     防具（鉄: 防御3）装備時の被ダメ(新)
 ───────────────────────────────────────────────────────────────────────────────────
 Stg 1〜3     1 / (ボス 3)              1 / (ボス 1)               1（最低保証）
 Stg 4〜5     2〜3                      1                         1（最低保証）
 Stg 6        3 / (ボス 4)              2 / (ボス 2)               1（最低保証）
 Stg 9        5 / (ボス 7)              2 / (ボス 2)               1（最低保証）
 Stg 12       6 / (ボス 9)              3 / (ボス 3)               1（最低保証）
 Stg 15       8 / (ボス 12)             3 / (ボス 3)               1（最低保証）
 Stg 16       8                         4                         1（4 - 3 = 1）
```

## 2. 実装詳細

### A. 通常敵の攻撃力計算式の変更 (`src/gameData.ts`)
`GAME_CONFIG.calculateEnemyAttack` を以下のように更新します：

```ts
// 変更前
calculateEnemyAttack: (stage: number) => {
  return Math.floor(1 + (stage - 1) * 0.5);
},

// 変更後（5ステージごとに+1加算、HP増加ペースと一致）
calculateEnemyAttack: (stage: number) => {
  return 1 + Math.floor((stage - 1) / 5);
},
```

### B. ボス出現時の攻撃力計算の変更 (`src/App.tsx`)
`handleTriggerBoss` におけるボス攻撃力の算出を、1.5倍から「通常敵と同等」に変更します：

```ts
// 変更前
const calculatedBossAtk = Math.floor(stageEnemyAtk * 1.5);

// 変更後（倍率なし、通常敵と同じ攻撃力）
const calculatedBossAtk = stageEnemyAtk;
```
